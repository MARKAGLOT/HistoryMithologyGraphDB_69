## 📌 Описание проекта
Данный проект представляет собой реализацию графовой базы данных на базе **MS SQL Server**. Тематика проекта — мифологические существа, боги и их взаимодействия (сражения, места обитания, родственные связи).

## 📂 Структура репозитория
* **`img/`** — иконки богов (`GodX.png`), существ (`creatureX.png`) и локаций (`LocationX.png`) для визуализации.
* **`MythologySQL(1-6).sql`** — полный скрипт создания базы данных, узлов (Nodes), ребер (Edges) и выполнения аналитических запросов.
* **`MythologyGraphDB.bak`** — бэкап базы данных для восстановления в среде SQL Server Management Studio.
* **`MythologyDioram.drawio`** — графическая схема структуры графа и связей между сущностями.
* **`MythologyPwerBIgraph.pbix`** — файл отчета Power BI с интерактивной визуализацией графа (Force-Directed Graph).
* **`NewTask.txt`** — описание теоретической задачи по применению графовых БД в системе мониторинга каршеринга (пункт №10 задания).

## 📊 Ключевые возможности
* Визуализация битв: стрелки указывают направление от победителя к проигравшему.
* Анализ локаций: группировка существ и богов по местам обитания.
* Использование встроенных функций SQL Graph (например, `MATCH`).
